# Website Screenshots

Place your website screenshots in this folder with these exact filenames:

## Required Images

1. **velogo.webp** - Screenshot of VeLogo restaurant delivery app
   - Recommended size: 1600x1000px (16:10 ratio)
   - Format: WebP for best performance
   - Keep under 200KB

2. **reflectai.webp** - Screenshot of ReflectAI student tracking system
   - Recommended size: 1600x1000px (16:10 ratio)
   - Format: WebP for best performance
   - Keep under 200KB

## How to Take Screenshots

1. Visit the live website
2. Take a full-page screenshot or hero section screenshot
3. Resize to 1600x1000px
4. Convert to WebP format using:
   - [Squoosh](https://squoosh.app/)
   - [TinyPNG](https://tinypng.com/)
   - Photoshop/GIMP with WebP export

## Temporary Placeholders

Until you add the real screenshots, the site will show broken image icons. The layout will still work correctly.

## Alternative: Use PNG/JPG

If you can't create WebP files, you can use PNG or JPG instead:
- Update the file extensions in `src/content.js`
- Change from `.webp` to `.png` or `.jpg`
