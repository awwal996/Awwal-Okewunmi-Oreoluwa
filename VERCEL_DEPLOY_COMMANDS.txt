YOUR CODE IS COMMITTED AND READY TO DEPLOY!

================================================================================
  STEP 1: CREATE GITHUB REPOSITORY
================================================================================

1. Go to: https://github.com/new

2. Repository settings:
   Name: okewunmi-portfolio
   Visibility: Public
   DO NOT initialize with README

3. Click "Create repository"

4. Copy your repository URL (example):
   https://github.com/YOUR_USERNAME/okewunmi-portfolio.git

================================================================================
  STEP 2: PUSH TO GITHUB
================================================================================

Run these commands in PowerShell:

cd "c:\Users\HP\OneDrive\Documents\3d web"

# Add GitHub as remote (REPLACE YOUR_USERNAME with your actual username)
git remote add origin https://github.com/YOUR_USERNAME/okewunmi-portfolio.git

# Push to GitHub
git push -u origin master

AUTHENTICATION:
- Username: Your GitHub username
- Password: Use Personal Access Token (NOT your password)
  Get token at: https://github.com/settings/tokens
  - Generate new token (classic)
  - Select "repo" scope
  - Copy token and paste as password

================================================================================
  STEP 3: DEPLOY ON VERCEL
================================================================================

1. Go to: https://vercel.com

2. Click "Continue with GitHub" (sign up/login)

3. Click "Add New..." → "Project"

4. Find "okewunmi-portfolio" → Click "Import"

5. Configure project:
   Framework Preset: Vite (auto-detected)
   Build Command: npm run build
   Output Directory: dist
   
6. Click "Deploy"

7. Wait 1-2 minutes...

8. DONE! Your portfolio is live! 🎉

YOUR LIVE URL:
https://okewunmi-portfolio.vercel.app
(or your chosen project name)

================================================================================

git push

Vercel will automatically redeploy!

================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: Can't push to GitHub
FIX: Use Personal Access Token, not password
     Get token: https://github.com/settings/tokens

ISSUE: Build failed on Vercel
FIX: Test build locally first:
     npm run build
     
ISSUE: Wrong GitHub remote
FIX: Remove and re-add:
     git remote remove origin
     git remote add origin <YOUR_REPO_URL>
